雪梅清理 v2.5.4 — 原生 AppKit 版

本版彻底停止使用 JXA/osascript 作为 GUI 主进程。

架构：
- Objective-C + AppKit 原生窗口
- zsh 仅作为扫描/清理/更新后端
- 安装时使用 Apple clang 在本机编译一次
- 安装完成后运行 Contents/MacOS/XueMeiCleanerNative 原生 Mach-O
- 不再由终端或 osascript 托管窗口

界面：
- 总览
- 智能扫描
- 分类勾选清理
- 用户日志默认不勾选
- 大文件
- 保护中心
- 软件更新
- 关于

安全：
- 不使用 sudo
- 不执行 docker prune
- 默认保护 Chrome/TikTok、Codex、IOTA/SN9、Docker、SSH、Keychain、钱包/密钥、源码和个人文件

更新：
- 本地 ZIP 更新
- HTTPS 在线更新
- SHA256 校验
- 新版先本机 clang 编译并校验
- 更新前备份
- 失败自动回滚

v2.5.1 极速全盘扫描修复：

- 用户个人目录里的安装包标记为“个人安装包”，继续交给安装包清理模块判断失效/损坏/已安装。


v4.1.5 未知来源深度识别：
- /private/var/folders 识别为“系统缓存”，其中 ZIP/IMG 不再算普通安装包。
- /opt、/usr/local、/Library/Developer 识别为开发工具目录。
- Application Support 识别为“应用支持资源”。
- Frameworks / Resources / Runtime / SDK / Toolchains /
  node_modules / site-packages / Python / Java / Flutter / Android /
  Parallels / VirtualBox / VMware 等路径识别为“运行时/工具资源”。
- 未确认来源的 ZIP/DMG/ISO/PKG 显示为“其他压缩资源”，默认仅查看。
- 系统缓存、应用支持、运行时资源均使用独立保护标签。
- 顶部汇总不再把这些受保护压缩资源计入真正安装包。
